# SportEdge – חיזוי ספורט לייב

אפליקציית ווב בעברית שמחשבת הסתברויות **ניצחון / תיקו / הפסד (1X2)** לכל משחק – לפני המשחק ובזמן אמת – משווה אותן ליחסי הסוכנויות, ומסמנת **הימורי ערך** (EV חיובי) לנחשי Winner ו-Bet365.

> ⚠️ **שקיפות:** אין מודל שמבטיח רווח. לסוכנות יש עמלה מובנית (בווינר היא גבוהה במיוחד), והשוק בליגות הגדולות יעיל מאוד. האפליקציה נותנת הסתברויות מכוילות, מראה בדיוק כמה היא צדקה בעבר, ומזהה מקרים שבהם היחס גבוה מההסתברות – זה כל היתרון שאפשר להשיג באופן כן. הימרו באחריות.

## הפעלה

דרוש Node.js 18 ומעלה. אין תלויות חיצוניות – לא צריך `npm install`.

```bash
cd sports-predictor
npm start            # http://localhost:3000
```

בהפעלה הראשונה השרת מוריד היסטוריית משחקים של כל הליגות (בערך דקה; ליגות ישראל ויורוליג דרך TheSportsDB החינמי עלולות לקחת כמה דקות בגלל הגבלת קצב). הכל נשמר ב-`data/cache` וההפעלות הבאות מהירות.

## ענפים וליגות

* **כדורגל:** ליגת העל, הליגה הלאומית, ליגת האלופות, הליגה האירופית, הקונפרנס, פרמייר ליג, לה ליגה, סרייה A, בונדסליגה, ליג 1, צ'מפיונשיפ, הולנד, פורטוגל, טורקיה, בלגיה, סקוטלנד, יוון, אוסטריה, דנמרק, קפריסין, סעודיה, MLS, ברזיל, ארגנטינה, מקסיקו, מוקדמות מונדיאל, ליגת האומות, ידידות.
* **כדורסל:** ליגת העל, יורוליג, יורוקאפ, ליגת האלופות FIBA, NBA, NCAA.
* **טניס:** ATP, WTA (כולל לייב לפי מערכות/משחקונים ומגיש).
* **פוטבול:** NFL, מכללות. **הוקי:** NHL. **בייסבול:** MLB.

## המודלים

* **כדורגל / הוקי / בייסבול** – מודל Poisson בסגנון Dixon-Coles: כוח התקפה והגנה לכל קבוצה, יתרון ביתיות, משקל דועך לפי זמן (משחקים אחרונים חשובים יותר). כל ליגות הכדורגל מותאמות **במאגר אחד** – משחקי אירופה מחברים בין הליגות (כך גם מכבי ת"א או הפועל ב"ש מקבלות דירוג בסקאלה אירופית). ממטריצת התוצאות נגזרים כל השווקים.
* **כדורסל / פוטבול** – רגרסיית התקפה/הגנה עם רגולריזציה; התפלגות נורמלית של ההפרש עם הארכה בתיקו, כך שאפשר לתמחר קווי ווינר עם X.
* **טניס** – דירוג עולמי → סיכוי שמירת הגשה → שרשרת מרקוב משחקון→מערכה→משחק.
* **שילוב עם השוק** – היחסים של הסוכנויות מומרים להסתברויות אחרי הסרת עמלה (שיטת Power), ובכדורגל גם לשערים צפויים. ההסתברות ה"הוגנת" = שילוב של המודל עם השוק (ברירת מחדל 30% מודל, ניתן לשינוי בהגדרות). המשקל של המודל **גדל עם מספר המשחקים** שיש על שתי הקבוצות ומגיע למלוא ההגדרה רק אחרי 12 משחקים – כך קבוצות עם מעט נתונים (מכללות בתחילת עונה, עולות חדשות) נשענות על השוק ולא מייצרות "ערך" מדומה. בכדורסל/פוטבול השילוב נעשה במרחב ההסתברות מול ה-moneyline, ופיזור התוצאות נגזר מהשוק עצמו (spread + moneyline).
* **לייב** – השערים/נקודות הצפויים לזמן שנותר מחושבים לפי הדקה (קצב שערים עולה לאורך המשחק), תוצאה (קבוצה מפגרת לוחצת), כרטיסים אדומים, שעון ורבע, קצב הקליעה בפועל.
* **ניהול קופה** – קריטריון קלי חלקי (ברירת מחדל ¼) עם תקרה לאחוז מהקופה.

### תוצאות backtest (נמדד ב-19.11.2026, 8 שבועות אחרונים, בלי הצצה לעתיד)

| מאגר | משחקים | הפייבוריט ניצח | Brier skill מול בסיס |
|---|---|---|---|
| כדורגל (1X2, שלוש תוצאות) | 1,406 | 54.1% | +9.7% |
| NBA | 288 | 61.1% | +9.4% |
| NHL | 338 | 58.6% | +4.6% |
| NFL | 117 | 66.7% | +16.5% |
| יורוליג + ליגת העל בכדורסל | 103 | 62.1% | +9.5% |

הנתונים מתעדכנים במסך "ביצועי המודל". זה מודל טוב יותר מניחוש – **אבל זה לא אומר שהוא מנצח את השוק**; את זה בודקים במסך "תיעוד חי" לאורך מאות משחקים.

## מקורות נתונים

| מקור | מפתח | מה מגיע ממנו |
|---|---|---|
| ESPN | לא צריך | תוצאות לייב, היסטוריה, טבלאות, פציעות, יחסי DraftKings (כולל פתיחה→סגירה), ESPN Predictor, דירוג טניס |
| TheSportsDB | חינמי (`123`) / פרימיום | ליגות ישראל, יורוליג, יורוקאפ, BCL. מפתח פרימיום נותן לייב מלא וקצב בקשות גבוה |
| The Odds API | `ODDS_API_KEY` | יחסים מעשרות סוכנויות (Pinnacle, Betfair, William Hill, Unibet…) – שוק חד יותר, "יחס הכי טוב" |
| API-Football | `APIFOOTBALL_KEY` | **יחסי Bet365** לכדורגל (1X2, מעל/מתחת, שתיהן יבקיעו, סיכוי כפול) |

מעתיקים את `.env.example` ל-`.env`, ממלאים מפתחות ומפעילים מחדש. ל-Winner אין API ציבורי – מקלידים את היחסים במחשבון הערך שבעמוד המשחק (נשמרים בדפדפן).

> שני ספקי היחסים בתשלום/מפתח (The Odds API, API-Football) מומשו לפי התיעוד הרשמי אך **לא נבדקו מול שרת אמיתי** בסביבת הפיתוח (לא היה מפתח). ESPN ו-TheSportsDB נבדקו מול נתונים חיים.

## מבנה

```
server/
  index.js            שרת HTTP + API
  engine.js           איחוד נתונים, מאגרי דירוג, חיזוי, לייב, ערך
  backtest.js         backtest ותיעוד חי
  tracker.js          מעקב הימורים וסגירה אוטומטית
  leagues.js          קטלוג ליגות
  models/             goals.js · points.js · tennis.js · odds.js
  providers/          espn.js · tsdb.js · oddsapi.js · apifootball.js
public/               ממשק (HTML/CSS/JS ללא build)
test/                 בדיקות למודלים (npm test)
data/                 מטמון, היסטוריית חיזויים, הימורים (לא נכנס ל-git)
```
